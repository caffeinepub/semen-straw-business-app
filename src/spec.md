# Specification

## Summary
**Goal:** Build a semen straw inventory management application for tracking livestock breeding inventory with professional agricultural design.

**Planned changes:**
- Create backend data model for semen straw records (straw ID, bull identification, collection date, quality grade, storage location, availability status)
- Implement backend CRUD operations and status management (add, update, mark as sold/used, retrieve inventory)
- Build frontend dashboard with inventory table/card view, filterable by status and searchable by bull ID
- Create frontend form for adding new semen straw records with all required fields
- Implement frontend edit functionality to update records and change status
- Apply agricultural-themed design with earthy color palette (greens, browns, cream) and professional typography

**User-visible outcome:** Users can manage their semen straw inventory through a professional web interface, adding new records, tracking straws by bull ID and status, and updating availability as straws are sold or used.
